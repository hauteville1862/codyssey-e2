# 세계 문학 작가 퀴즈

터미널에서 동작하는 콘솔 기반 퀴즈 게임입니다. Python 클래스와 JSON 파일 입출력을 활용해
퀴즈를 풀고, 새 문제를 추가하고, 프로그램을 종료했다가 다시 실행해도 데이터(문제·최고 점수)가
유지되도록 구현했습니다.

## 1. 프로젝트 개요

- **분야**: 입학연수 · 개발 입문 미션 (Python + Git 기초)
- **형태**: 터미널에서 동작하는 콘솔 퀴즈 게임 1개 + GitHub 저장소 1개
- **핵심 기능**: 퀴즈 풀기 / 퀴즈 추가 / 퀴즈 목록 보기 / 최고 점수 확인
- **핵심 학습 목표**
  - 클래스(`Quiz`, `QuizGame`)로 역할을 나눠 코드를 구조화
  - JSON 파일(`state.json`)로 데이터를 저장·불러와 "데이터 영속성" 구현
  - 잘못된 입력, 파일 손상, 강제 종료(Ctrl+C) 상황에서도 프로그램이 안전하게 동작하도록 예외 처리
  - Git으로 기능 단위 커밋 및 브랜치 작업 이력 관리

## 2. 퀴즈 주제 선정 이유

주제는 **세계 문학 작가**입니다. 평소 관심 있던 고전 문학 작품들의 저자를 스스로 정리하며
공부할 겸, 단순 암기가 아니라 "작품 → 작가"를 연결해 떠올리는 문제를 만들어보고 싶어 선정했습니다.
빅토르 위고, 조지 오웰, 헤르만 헤세, F. 스콧 피츠제럴드, 표도르 도스토옙스키 등 시대와 국가가 다른
작가 5명을 기본 문제로 구성해 다양성을 갖췄습니다.

## 3. 실행 방법

Python 3.10 이상이 필요합니다 (표준 라이브러리만 사용, 외부 패키지 설치 불필요).

```bash
cd apps
python main.py
```

실행 후 메뉴에서 번호(1~5)를 입력해 기능을 선택합니다.

```
========================================
      📚 세계 문학 작가 퀴즈 📚
========================================
  1. 퀴즈 시작
  2. 퀴즈 추가
  3. 퀴즈 목록 보기
  4. 최고 점수 확인
  5. 종료
----------------------------------------
메뉴를 선택하세요 (1-5):
```

> `main.py`는 실행 위치(cwd)와 관계없이 항상 **`apps/state.json`**(main.py와 같은 폴더)을 읽고 씁니다
> (스크립트 경로 기준으로 파일 위치를 계산하므로, 프로젝트 루트 등 다른 위치에서 실행해도 동일하게 동작합니다).

## 4. 기능 목록

| 메뉴 | 기능 | 설명 |
|---|---|---|
| 1 | 퀴즈 시작 | 저장된 문제를 순서대로 출제하고, 정답 입력 시 즉시 정답/오답을 알려줍니다. 모든 문제를 풀면 최종 점수를 보여주고, 기존 최고 점수보다 높으면 `state.json`에 갱신·저장합니다. 등록된 문제가 없으면 안내 후 메뉴로 돌아갑니다. |
| 2 | 퀴즈 추가 | 문제 내용, 보기 4개, 정답 번호(1~4)를 입력받아 `state.json`에 새 문제로 추가합니다. |
| 3 | 퀴즈 목록 보기 | 현재 등록된 모든 문제와 정답 번호를 목록으로 보여줍니다. |
| 4 | 최고 점수 확인 | 지금까지 기록된 최고 점수를 보여줍니다. |
| 5 | 종료 | 프로그램을 안전하게 종료합니다. |

### 입력 예외 처리

메뉴 선택, 퀴즈 정답, 퀴즈 추가 시 정답 번호 입력 등 숫자를 입력받는 모든 곳에서 아래 케이스를 처리합니다.

- 입력 앞뒤 공백 제거 후 처리 (예: `" 1 "` → `1`)
- 숫자가 아닌 값(`abc` 등) 입력 시 안내 메시지 후 재입력
- 허용 범위를 벗어난 숫자(메뉴 `9`, 정답 `0` 등) 입력 시 안내 메시지 후 재입력
- 빈 입력(Enter만 입력) 시 안내 메시지 후 재입력
- 문제/보기 내용은 빈 문자열을 허용하지 않고 재입력을 요구

또한 프로그램 실행 중 `Ctrl+C`(`KeyboardInterrupt`) 또는 입력 스트림 종료(`EOFError`)가 발생해도
스택 트레이스 없이 안내 메시지를 출력하고 정상 종료(exit code 0)합니다.

`state.json` 파일이 없거나(첫 실행) 형식이 손상되어 파싱에 실패하면, 기본 퀴즈 데이터(문학 작가
문제 5개, 최고 점수 0점)로 자동 초기화하고 그 내용을 파일에 다시 저장해 프로그램이 항상 정상
실행되도록 합니다.

## 5. 파일 구조

```
codyssey-e2/
├── README.md          # 프로젝트 설명 문서 (본 파일)
├── .gitignore
├── docs/
│   ├── mission-2       # 미션 요구사항 원문
│   └── evaluations.md  # 평가문항
└── apps/
    ├── main.py          # 진입점: 메뉴 출력, 입력 검증, 파일 로드/저장, 각 기능 실행 함수
    ├── Quiz.py          # Quiz 클래스: 문제 1개(question/choices/answer)를 표현
    ├── QuizGame.py      # QuizGame 클래스: 퀴즈 진행(출제·정답 확인·점수 계산)을 담당
    └── state.json       # 퀴즈 데이터 + 최고 점수 저장 파일 (UTF-8)
```

### 클래스 책임 분리

- **`Quiz`** — 문제 하나의 데이터만 표현하는 값 객체입니다. `question`(문제), `choices`(보기 4개),
  `answer`(정답 번호 1~4) 속성을 가집니다.
- **`QuizGame`** — 퀴즈 "진행"을 담당합니다. 문제 목록을 순회하며 출제하고(`next_question`),
  사용자 입력을 검증한 뒤 정답 여부를 판정·점수를 누적합니다(`check_answer`).
- **`main.py`** — "입력 처리(메뉴/추가 시 검증)"와 "데이터 저장·불러오기(JSON 입출력)"를 담당합니다.
  `Quiz`/`QuizGame`은 파일 입출력을 전혀 알지 못하고, `main.py`가 `state.json`에서 읽은 `dict`를
  `Quiz` 인스턴스로 변환해 `QuizGame`에 넘겨주는 구조로, 화면/게임 로직과 저장 로직을 분리했습니다.

## 6. 데이터 파일 설명 (`state.json`)

- **경로**: `apps/state.json` (main.py와 같은 폴더), 인코딩은 UTF-8
- **역할**: 등록된 전체 퀴즈 목록과 지금까지의 최고 점수를 저장해, 프로그램을 종료했다가 다시
  실행해도 데이터가 유지되도록 합니다.
- **스키마**

  ```json
  {
    "high_score": 0,
    "questions": [
      {
        "question": "'레 미제라블'의 저자로 프랑스의 대문호인 작가는?",
        "options": ["빅토르 위고", "에밀 졸라", "기 드 모파상", "알베르 카뮈"],
        "answer": 1
      }
    ]
  }
  ```

  | 필드 | 타입 | 설명 |
  |---|---|---|
  | `high_score` | `int` | 지금까지 기록된 최고 점수(맞힌 문제 수) |
  | `questions` | `list[dict]` | 등록된 전체 문제 목록 |
  | `questions[].question` | `str` | 문제 내용 (`Quiz.question`에 대응) |
  | `questions[].options` | `list[str]` (4개) | 보기 4개 (`Quiz.choices`에 대응) |
  | `questions[].answer` | `int` (1~4) | 정답 보기 번호 (`Quiz.answer`에 대응) |

  `dict`를 사용해 `question`/`options`/`answer`처럼 필드에 이름을 붙여두면, 리스트로만 저장하는
  것보다 어떤 값이 무엇을 의미하는지 명확하고, 이후 필드가 추가되어도(예: 힌트) 기존 데이터와
  호환되도록 확장하기 쉽습니다.

## 7. 알려진 제한 사항 / 보너스 과제

- 미션 명세는 `state.json`을 **프로젝트 루트**에 두는 것을 기본으로 안내하지만, 이 프로젝트에서는
  실행 스크립트(`main.py`)와 같은 `apps` 폴더에 두는 구조를 선택했습니다. 경로만 다를 뿐 UTF-8
  인코딩, 스키마, 로드/저장 로직은 동일합니다.
- 랜덤 출제, 문제 수 선택, 힌트, 퀴즈 삭제, 점수 기록 히스토리 등 보너스 과제는 아직 구현하지
  않았습니다.
- Git 브랜치 생성·병합, clone/pull 실습은 코드와 별개로 실습 후 `git log --oneline --graph`
  스크린샷 등으로 별도 제출이 필요합니다.
